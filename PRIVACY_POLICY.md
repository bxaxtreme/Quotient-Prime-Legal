INTRODUCTION

This Privacy Policy explains what information Quotient Prime collects, how it is used, and what rights you have. By adding or using Quotient Prime in your Discord server, you agree to this Privacy Policy.


INFORMATION WE COLLECT

Quotient Prime only collects the data needed to run its features.

Server data: Server ID, server name, channel IDs, role IDs, and the settings configured by server admins.

User data: Discord User ID, username, and role information when it is needed for commands, moderation, tournament or scrim registration, and other bot features.

Message content: The bot reads messages only to detect and run commands, and to power features enabled by server admins such as auto moderation, auto responses, and registration channels. Message content is processed in real time and is not stored unless a feature clearly needs it, such as a saved registration entry, ticket, or log.

Usage data: Basic command usage and error logs used for debugging and improving the bot.

We do not collect passwords, payment details, email addresses, or any private messages.


PRIVILEGED INTENTS

Quotient Prime uses the following Discord privileged intents only where needed.

Server Members Intent: To identify members, manage roles, verify registrations, and run moderation and welcome features.

Message Content Intent: To read commands and to run moderation and automation features configured by server admins.

Presence Intent: Not used for tracking users. It is used only if a feature specifically needs it.

This data is never used for any purpose other than providing the bot's features.


HOW WE USE INFORMATION

We use the collected information to provide and operate bot features, to save server settings, to prevent abuse and spam, to fix bugs and improve performance, and to provide support.


DATA SHARING

We do not sell, rent, or trade your data. Data is not shared with any third party, except where required by law or where needed to protect the safety of users and the bot. Data may be stored with trusted hosting and database providers that are used only to run the bot.


DATA STORAGE AND SECURITY

Data is stored in secured databases with limited access. We take reasonable steps to protect your data, but no method of storage or transmission is completely secure.


DATA RETENTION AND DELETION

Server data is kept while the bot is in your server. When the bot is removed, the related server data may be deleted within a reasonable time. You can request deletion of your data at any time by joining our support server and contacting the developer. We will process valid requests as soon as possible.


CHILDREN

Quotient Prime is intended for users who meet Discord's minimum age requirement. We do not knowingly collect data from anyone below that age. If you believe such data has been collected, contact us and it will be removed.


THIRD PARTY SERVICES

Quotient Prime runs on Discord. Your use of Discord is covered by the Discord Terms of Service and the Discord Privacy Policy. We are not responsible for the practices of Discord or other third parties.
